## a. Problem Statement

Customer churn — the loss of subscribers to a competitor or cancellation of a
service — is one of the most costly problems for subscription-based
businesses such as telecom operators. This project builds and compares five
supervised classification models that predict whether a telecom customer
will churn (cancel their subscription) based on their account information,
services subscribed, and billing details. The best-performing model is
exposed through an interactive Streamlit web application that lets a user
upload customer data, choose a model, and instantly view its predictive
performance.

## b. Dataset Description

- **Name:** Telco Customer Churn (IBM Sample Data Set)
- **Source:** Publicly available dataset, originally released as an IBM
  sample dataset and widely mirrored on Kaggle as *"Telco Customer Churn"*
  (`WA_Fn-UseC_-Telco-Customer-Churn.csv`).
- **Instances:** 7,043 customers
- **Features:** 19 (after dropping the non-predictive `customerID` column),
  satisfying the assignment's minimum of 12 features and 500 instances.
- **Feature types:** a mix of demographic fields (`gender`, `SeniorCitizen`,
  `Partner`, `Dependents`), account/contract fields (`tenure`, `Contract`,
  `PaperlessBilling`, `PaymentMethod`, `MonthlyCharges`, `TotalCharges`), and
  subscribed-services fields (`PhoneService`, `MultipleLines`,
  `InternetService`, `OnlineSecurity`, `OnlineBackup`, `DeviceProtection`,
  `TechSupport`, `StreamingTV`, `StreamingMovies`).
- **Target variable:** `Churn` — binary (`Yes` / `No`, encoded as 1 / 0).
  Class balance: ~26.5% churned, ~73.5% retained.
- **Preprocessing:** `TotalCharges` (stored as text) is coerced to numeric
  with missing values imputed by the median; numeric features are
  standardized; categorical features are one-hot encoded. All preprocessing
  is bundled into a single scikit-learn `Pipeline` alongside each classifier,
  so the saved model files can be applied directly to raw CSV rows.
- **Split:** stratified 80% train (5,634 rows, used only for model training)
  / 20% test (1,409 rows, saved as `test_data.csv` and used both for the
  metrics below and for the Streamlit demo).

## d. Models Used

### Observations

| ML Model Name | Observation about model performance |
|---|---|
| Logistic Regression | Best overall balance of accuracy, AUC, and MCC. The churn decision boundary in this dataset is close to linear in the standardized/encoded features (tenure, contract type, and charges dominate), so a simple linear model generalizes well without overfitting. |
| Decision Tree | Weakest of the five. A single tree (even depth-limited) overfits idiosyncrasies of the training split and has the lowest AUC and MCC — it doesn't average out noise the way the ensemble does. |
| kNN | Middle-of-the-pack. Performs reasonably once features are scaled, but distance-based similarity is diluted by the large number of one-hot encoded categorical dimensions, limiting further gains. |
| Naive Bayes (Gaussian) | Lowest accuracy and precision but by far the highest recall (0.837) — it aggressively flags customers as "at risk," which is useful if the business goal is to catch as many potential churners as possible even at the cost of false alarms. The independence assumption between features clearly doesn't hold here, hurting precision. |
| Random Forest (Ensemble) | Close second to Logistic Regression, with the highest precision. Averaging many trees fixes most of the single Decision Tree's overfitting, but doesn't beat the linear model on this particular feature set. |
| **Overall Winner for your dataset?** | **Logistic Regression** — highest accuracy (0.8055), highest AUC (0.8419), and highest MCC (0.4790) of all five models on this dataset. |

## How to Reproduce

```bash
pip install -r requirements.txt
cd model
python prepare_data.py      # regenerates train_data.csv / ../test_data.csv
python train_models.py      # retrains all 5 models + comparison_metrics.csv
cd ..
streamlit run app.py        # launches the interactive demo locally
```

## Streamlit App Features

1. CSV upload (upload `test_data.csv`, or any file with the same 19 feature
   columns + `Churn` label column).
2. Model selection dropdown across all 5 trained classifiers.
3. Live display of Accuracy, AUC, Precision, Recall, F1, and MCC on the
   uploaded data.
4. Confusion matrix heatmap and full classification report.
